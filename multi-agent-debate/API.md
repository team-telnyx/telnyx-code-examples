# API Reference — Multi-Agent Debate

All endpoints are served from a single Telnyx Edge Function entry point (`src/index.ts`). The function exports a default `fetch` handler that routes incoming HTTP requests to the appropriate internal handler.

---

## 1. Start Debate

Creates a new debate session with two opposing agents and begins the turn-based argument flow.

### `POST /debate`

#### Request Body

| Field       | Type     | Required | Description                                      |
|-------------|----------|----------|--------------------------------------------------|
| `topic`     | `string` | Yes      | The debate topic (e.g. `"AI should be regulated"`). |
| `proSide`   | `string` | Yes      | Label for the pro agent (e.g. `"Pro"`).          |
| `conSide`   | `string` | Yes      | Label for the con agent (e.g. `"Con"`).          |

#### Example Request

```bash
curl -X POST https://<edge-function-url>/debate \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "AI should be regulated",
    "proSide": "Pro",
    "conSide": "Con"
  }'
```

#### Response Schema

**Status Code: `201`**

```json
{
  "debateId": "debate_1234567890",
  "topic": "AI should be regulated",
  "status": "started",
  "currentTurn": "pro",
  "createdAt": "2024-01-15T10:00:00.000Z"
}
```

| Field          | Type     | Description                                         |
|----------------|----------|-----------------------------------------------------|
| `debateId`     | `string` | Unique identifier for the debate session.           |
| `topic`        | `string` | The debate topic.                                   |
| `status`       | `string` | Current status (`"started"`, `"in_progress"`, `"ended"`). |
| `currentTurn`  | `string` | Which agent's turn it is (`"pro"` or `"con"`).      |
| `createdAt`    | `string` | ISO 8601 timestamp of session creation.             |

#### Status Codes

| Code | Meaning                             |
|------|-------------------------------------|
| 201  | Debate session created successfully.|
| 400  | Invalid request body (missing fields). |
| 500  | Internal server error.              |

## 2. Get Debate State

Retrieves the current state of a debate session, including all arguments generated so far and current vote counts.

### `GET /debate/{debateId}`

#### Path Parameters

| Field      | Type     | Required | Description                          |
|------------|----------|----------|--------------------------------------|
| `debateId` | `string` | Yes      | Unique identifier of the debate.     |

#### Example Request

```bash
curl https://<edge-function-url>/debate/debate_1234567890
```

#### Response Schema

**Status Code: `200`**

```json
{
  "debateId": "debate_1234567890",
  "topic": "AI should be regulated",
  "status": "in_progress",
  "currentTurn": "con",
  "arguments": [
    {
      "agent": "Pro",
      "text": "Regulation ensures responsible AI development...",
      "turn": 1,
      "timestamp": "2024-01-15T10:00:05.000Z"
    },
    {
      "agent": "Con",
      "text": "Over-regulation stifles innovation...",
      "turn": 2,
      "timestamp": "2024-01-15T10:00:12.000Z"
    }
  ],
  "votes": {
    "pro": 42,
    "con": 38
  },
  "createdAt": "2024-01-15T10:00:00.000Z",
  "updatedAt": "2024-01-15T10:00:12.000Z"
}
```

| Field          | Type       | Description                                         |
|----------------|------------|-----------------------------------------------------|
| `debateId`     | `string`   | Unique identifier for the debate session.           |
| `topic`        | `string`   | The debate topic.                                   |
| `status`       | `string`   | Current status (`"started"`, `"in_progress"`, `"ended"`). |
| `currentTurn`  | `string`   | Which agent's turn it is (`"pro"` or `"con"`).      |
| `arguments`    | `array`    | List of all arguments generated in the debate.      |
| `arguments[].agent` | `string` | Label of the agent that generated the argument.   |
| `arguments[].text`  | `string` | The argument text generated by the agent.         |
| `arguments[].turn`  | `number` | Turn number (1-indexed).                          |
| `arguments[].timestamp` | `string` | ISO 8601 timestamp of the argument.            |
| `votes`        | `object`   | Current vote tally.                                 |
| `votes.pro`    | `number`   | Number of votes for the pro side.                   |
| `votes.con`    | `number`   | Number of votes for the con side.                   |
| `createdAt`    | `string`   | ISO 8601 timestamp of session creation.             |
| `updatedAt`    | `string`   | ISO 8601 timestamp of last state update.            |

#### Status Codes

| Code | Meaning                              |
|------|--------------------------------------|
| 200  | Debate state retrieved successfully. |
| 404  | Debate session not found.            |
| 500  | Internal server error.               |

## 3. End Debate

Ends an active debate session and computes the winner based on accumulated audience votes.

### `POST /debate/{debateId}/end`

#### Path Parameters

| Field      | Type     | Required | Description                          |
|------------|----------|----------|--------------------------------------|
| `debateId` | `string` | Yes      | Unique identifier of the debate.     |

#### Example Request

```bash
curl -X POST https://<edge-function-url>/debate/debate_1234567890/end
```

#### Response Schema

**Status Code: `200`**

```json
{
  "debateId": "debate_1234567890",
  "topic": "AI should be regulated",
  "status": "ended",
  "winner": "Pro",
  "finalVotes": {
    "pro": 42,
    "con": 38
  },
  "totalArguments": 10,
  "endedAt": "2024-01-15T10:05:00.000Z"
}
```

| Field            | Type     | Description                                         |
|------------------|----------|-----------------------------------------------------|
| `debateId`       | `string` | Unique identifier for the debate session.           |
| `topic`          | `string` | The debate topic.                                   |
| `status`         | `string` | Always `"ended"` for this response.                 |
| `winner`         | `string` | Label of the winning agent (`"Pro"` or `"Con"`).    |
| `finalVotes`     | `object` | Final vote tally.                                   |
| `finalVotes.pro` | `number` | Final votes for the pro side.                       |
| `finalVotes.con` | `number` | Final votes for the con side.                       |
| `totalArguments` | `number` | Total number of arguments generated during the debate. |
| `endedAt`        | `string` | ISO 8601 timestamp of debate end.                   |

#### Status Codes

| Code | Meaning                              |
|------|--------------------------------------|
| 200  | Debate ended successfully.           |
| 404  | Debate session not found.            |
| 409  | Debate already ended.                |
| 500  | Internal server error.               |

## WebSocket Endpoint

### `GET /ws/debate/{debateId}`

Establishes a WebSocket connection for live streaming of the debate conversation and receiving real-time vote updates.

#### Connection URL

```
wss://<edge-function-url>/ws/debate/{debateId}
```

#### Path Parameters

| Field      | Type     | Required | Description                          |
|------------|----------|----------|--------------------------------------|
| `debateId` | `string` | Yes      | Unique identifier of the debate.     |

#### WebSocket Messages (Server → Client)

**Argument Broadcast**

```json
{
  "type": "argument",
  "debateId": "debate_1234567890",
  "agent": "Pro",
  "text": "Regulation ensures responsible AI development...",
  "turn": 1,
  "timestamp": "2024-01-15T10:00:05.000Z"
}
```

**Vote Update**

```json
{
  "type": "vote_update",
  "debateId": "debate_1234567890",
  "votes": {
    "pro": 42,
    "con": 38
  }
}
```

**Debate Ended**

```json
{
  "type": "debate_ended",
  "debateId": "debate_1234567890",
  "winner": "Pro",
  "finalVotes": {
    "pro": 42,
    "con": 38
  }
}
```

#### WebSocket Messages (Client → Server)

**Audience Vote**

```json
{
  "type": "vote",
  "side": "pro"
}
```

| Field  | Type     | Required | Description                              |
|--------|----------|----------|------------------------------------------|
| `type` | `string` | Yes      | Must be `"vote"`.                        |
| `side` | `string` | Yes      | Which side to vote for (`"pro"` or `"con"`). |

#### WebSocket Status Codes

| Code | Meaning                              |
|------|--------------------------------------|
| 1000 | Normal closure.                      |
| 4004 | Debate session not found.            |
| 4009 | Invalid vote payload.                |
| 4401 | Unauthorized (no valid session).     |

## Error Response Schema

All HTTP error responses follow a consistent JSON shape:

```json
{
  "error": {
    "code": "string",
    "message": "A generic error message."
  }
}
```

| Field           | Type     | Description                                      |
|-----------------|----------|--------------------------------------------------|
| `error.code`    | `string` | Machine-readable error code.                     |
| `error.message` | `string` | Human-readable error message (no sensitive data).|

### Common Error Codes

| Code               | HTTP Status | Description                                      |
|--------------------|-------------|--------------------------------------------------|
| `invalid_request`  | 400         | Request body or parameters are invalid.          |
| `not_found`        | 404         | Requested resource (debate session) not found.   |
| `conflict`         | 409         | Operation conflicts with current state.          |
| `internal_error`   | 500         | Unexpected server-side error.                    |
